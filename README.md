#LUSC Genomic Database Project

#Project Summary

This project involved designing and implementing a MySQL database to transform raw genomic and clinical data into a system that 
can be queried for biological insight in patients with lung squamous cell carcinoma (LUSC). Raw patient, sample, mutation, and 
expression datasets were cleaned and standardized using Python scripts before being populated into the database. The final 
database organizes information across all datasets. Linux command line tools and SQL scripts were use to automate database 
creation and population. The completed database allows for querying of biologically relevant relationships like identifying 
mutated genes, examining mutation impact, and connecting mutations across different patient samples. 

# Tools and Technologies

- DBMS: MySQL
- Programming Languages: Python, SQL
- Operating Environment: Linux command line

# Data Source Summary

The database was built using publicly available genomic and clinical datasets for lung squamous cell carcinoma (LUSC). The datasets included:

- patient clinical information
- sample-level metadata
- somatic mutation data
- RNA-seq gene expression values

Primary files included:

```text
data_clinical_patient.txt
data_clinical_sample.txt
data_mutations.txt
data_mrna_seq_rpkm.txt
```

The source data contained missing values, inconsistent formatting, and partially overlapping gene sets, which required preprocessing and filtering before integration into the relational database.

# How to Recreate the Database

## Step 1 — Run Cleaning Scripts

Run the Python preprocessing scripts in the following order:

- 1_cleaningpatientfile.py
- 2_cleaningsamplefile.py
- 3_cleaningmutationfile.py

These scripts generate cleaned CSV files used for database population.

---

## Step 2 — Compare Gene Lists

- 7_comparinghugos.py

This compares genes in the mutation and expression datasets and generates a filtering report.

---

## Step 3 — Generate SQL Insert Files

Run the insert-generation scripts:

- 4_patient_sample_inserts.py
- 5_mutationsinserts.py
- 6_expressioninserts.py

This creates SQL insert files used to populate the database.

---

## Step 4 — Start MySQL

Open MySQL from the Linux command line:

```bash
mysql -h 127.0.0.1 -P 3306 -u root -pinstructor
```

Create and select the database:

```sql
CREATE DATABASE DatabaseProject;
USE DatabaseProject;
```

---

## Step 5 — Run SQL Schema Files

Run the schema creation files in this exact order:

```sql
SOURCE /media/sf_Database_Project/SQL/1_creatingtables.sql;
SOURCE /media/sf_Database_Project/SQL/2_adjusted_tables.sql;
```

The second file adds the final composite unique constraint to the `Variant` table.

---

## Step 6 — Populate the Database

Run the SQL insert files in the following exact order:

```sql
SOURCE /media/sf_Database_Project/SQL/3_insert_pt_spl.sql;
SOURCE /media/sf_Database_Project/SQL/4_mutations_inserts.sql;
SOURCE /media/sf_Database_Project/SQL/5_expression_inserts_filtered.sql;
SOURCE /media/sf_Database_Project/SQL/6_filtered_no_expressions.sql;
```

This order is required to maintain referential integrity between tables.

# Expected Final Result

After successful execution:

- all tables will be created in MySQL
- cleaned clinical, mutation, and expression data will be loaded
- duplicate variants will be prevented through composite uniqueness constraints
- foreign key relationships will enforce referential integrity
- genes without associated expression data will be filtered out

The completed database will support biological and clinical analysis queries such as:

- identifying highly mutated genes
- finding high-impact mutations
- comparing mutation burden across samples
- linking mutations with gene expression
- analyzing patient-level genomic patterns in LUSC
